# Astro 博客系统简介
Astro 是一个现代化的博客系统，支持多种模板和主题。
## 安装 Astro
你可以通过 npm 或 yarn 安装 Astro:
```bash
npm install astro
```
## 配置 Astro
配置 Astro 需要创建一个配置文件 `astro.config.js`:
```javascript
module.exports = {
  // 配置项
};
```
## 使用 Astro
使用 Astro 可以创建一个新的博客系统:
```bash
astro new my-blog
```
